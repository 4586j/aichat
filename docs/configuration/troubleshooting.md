# 常见问题与排查

## 联动没有发表情或推荐歌曲

先检查“让回应贴合此刻”的独立开关与原有媒体总开关。联动会有意控制频率：自动表情不连续发送；自然推歌每 5 次成功回复最多一次，疲惫或“少追问”时为 10 次，首次需等到第 5／10 次。倾诉、建议、任务场景、未知状态和音乐地址为空时不主动推歌。明确点歌可直接提出，例如“请推荐一首歌”，服务未配置时会显示待查询卡片。

若当前会话曾点击“本会话不再主动推荐”，静音会在刷新和重启后保留，可在聊天状态栏下方“恢复本会话推荐”；新会话独立。“这次不需要”只收起一条歌曲，点击“重新显示这首歌”恢复。反馈不会暂停当前音乐。表情场景或强度不合适时，到表情图库编辑标签；疲惫／倾诉场景不自动检索无法分类的联网图片。

## 聊天状态没有变化或判断不准确

在聊天状态栏打开详情，先检查“状态辅助方式”是否开启 AI 辅助、对应项目是否由你手动指定。手动项在 30 分钟有效期内不会被自动覆盖。自动判断需要模型按提示返回有效状态元数据，且必须引用本会话用户原话；模型未返回、格式错误、选项无效或依据不符时，应用保留尚有效的值或显示未知／默认状态，不额外补发模型请求。可以直接手动修改，或取消“由我指定”后在下次发言时重新判断。

短期状态最多 30 分钟后过期，新会话不会继承其他会话的状态。如果保存提示“状态已被另一处修改”或“熟悉程度已变化”，详情会保留未保存内容；核对后点击“重新读取”，确认放弃旧修改，再编辑保存。熟悉分数不因聊天条数直接增加，请先在记忆中核对并保存相关资料，详情中可以查看计入规则与依据。保存手动熟悉分数时必须填写依据。

适用于栖忆 1.0.0。可以向 AI 描述现象、发生步骤和经过遮盖的错误类型。真实 API Key、密码、授权码、Cookie 不要发送到聊天或公开仓库。AI 看到的是文档和有限的字段填写状态，不会据此假装实际测试过服务。

## 重启后 Key 或密码“不见了”

模型 API Key、音乐 Key、表情 Key 和 SMTP 密码只保留在服务进程内。输入框在保存后清空是正常现象，状态提示说明服务端是否有值。重启后需在设置中重新填写，或通过环境变量提供。只创建 `.env` 但执行 `npm start` 不会加载文件；请用 `node --env-file=.env server.mjs`。更换 SMTP 主机或用户名也会清除旧密码。

## 模型连接失败

确认先“保存设置”再“测试已保存的连接”，检查 Base URL 是否错误包含 `/chat/completions`、模型 ID 是否真实可用、Key 是否属于同一服务。401/403 通常与认证或权限有关，404 检查路径和模型，429 检查限流与额度。超时检查服务启动情况和网络。未配置模型时仍能直接阅读配置指南，但 AI 无法在线回答配置问题。

## AI 没有发送表情包

表情不是每轮必发。检查允许 AI 配图、本地图片启用状态，以及名称、场景和标签是否能表达当前语境。最近两条回复用过的图片会暂时排除。联网地址为空时仅用本地；联网需要兼容本项目的检索协议，普通网页和任意图片网址不适用。图源跨域时检查允许来源；动图需要点击加载，已删除的上传图在旧记录中无法恢复。

## 没有音乐、连接失败或没有声音

音乐地址为空时“音乐服务未配置”是预期状态。填写后先保存，再手动测试。确认源音乐平台在运行，基础地址能从 Node.js 服务所在机器访问，Key 和第三方登录状态有效。先尝试本地曲库，再检查在线来源；在线搜索成功不等于实际可播放。播放需要点击，检查播放器是否暂停、音量是否为零、浏览器或系统是否静音、音源编码是否可解码。修改服务地址后重新搜索旧歌曲。

## 邮件失败、部分接受或收不到

确认 SMTP 主机不含协议与路径，端口和加密方式匹配，服务商允许 SMTP，使用其要求的密码或独立授权码。用户名、发件地址与账号权限应匹配。测试成功只表示连接和认证成功。发送记录“部分接受”需核对已接受与已拒绝名单；不要向已接受的地址盲目重发。“服务器已接受”后收不到，可检查退信、垃圾邮件及服务商投递记录。显示“结果待核实”时先核实发件或收件情况，再决定是否重新发送。

## 宠物图片或动效没有显示

做动作时整体突然变小通常是静止图与动作图的主体比例不同。新版使用统一的构图校准数据，保留静止显示大小，并对齐动作的普通坐姿、中心与脚底；蹲下会自然变矮，跳起会自然离地。升级后刷新页面即可，不需要调整缩放或配置服务。自行更换动作图后，需要重新生成 `public/pet-framing.js`；直接替换图片可能让比例不匹配。

完整动作的普通姿势约每 85ms 切换，并持续加入轻微重心和呼吸变化；伸懒腰的顶点有意多停一会儿。升级后仍明显逐张停顿时，刷新页面以加载最新脚本。本地原有素材就能播放，不需要模型或外部服务；关闭轻动效或系统减少动态效果会停止所有动画。

先从顶部爪印入口进入小窝，确认“在聊天中显示宠物”已开启。关闭“开启轻动效”或系统开启“减少动态效果”时，停止眨眼与身体动作，但仍会切换静态表情，这是预期行为。疲惫时身体静止；倾诉、专注时减少小动作；开心的闭眼笑不会再次眨眼。页面隐藏或形象离开视野时暂停，回来后不会补播。若情绪没有带动表情，检查“让回应贴合此刻 → 宠物随对话状态表现”是否开启，以及当前对话状态是否有效。

宠物资源为项目 `public/assets/pets/` 中的本地 `*-v1.png`、`*-expressions-v2.webp` 和 `*-actions-v3.webp`，不需要新的配置。完整动作图缺失或尺寸无效时，仍有五种表情和原有小动作，招手／进食等会退回较小的形变动作；表情图也失败或浏览器无法绘制时回退原始静态形象，原图也失败时显示替代提示。完整动作图只在允许活动时加载，初次静止、休息或专注时没有该请求属于正常情况。恢复文件后刷新页面再试，和模型 Key 或外部图源无关。音乐动作只跟随实际播放，暂停、结束、缓冲和播放失败都会停止。手机键盘弹出时紧凑陪伴条会临时收起。互动过快时会提示刚刚收到，不会重复加分；稍等一秒再试即可。

## GitHub 指南更新失败

内置指南可以离线阅读，不依赖 GitHub。更新按钮只读取固定仓库 `4586j/aichat` 的文档包，不会上传设置、问题或密钥。仓库未公开、文档包尚未推送、网络不通或 GitHub 限流均可能导致更新失败，此时继续使用已验证的缓存或内置副本。文档包必须匹配本应用版本和格式；不会加载任意用户提供的网址。
