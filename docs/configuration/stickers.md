# 本地表情包与联网补充

适用于栖忆 1.0.0。进入“设置 → 让对话多一点表达”，调整后点击“保存媒体设置”。媒体设置与模型、邮件设置分别保存。

## 不配置联网服务也能使用

默认内置 6 张原创小叶贴纸。开启“允许 AI 搭配表情包”后，AI 根据聊天语境决定是否附图，每次最多一张，也可以不发送。为避免重复，最近两条 AI 回复使用过的表情会暂时排除。需要模型连接成功，普通文字模型即可按文字描述选图，不要求视觉模型。

在“本地表情图库”选择 PNG、JPEG、GIF 或 WebP，填写名称、使用场景和标签，点击“加入本地图库”。选图依据是这些文字，应用不会把图片内容自动传给聊天模型。每张最多 4 MiB、宽高不超过 4096；上传图库最多 100 张、合计 64 MiB。重复图片按内容去重。动图需要点击后加载和播放。

## 联网补充的服务地址

本地优先，没有合适素材且允许联网补充时才查询已配置服务。表情检索地址默认留空，留空就只用本地图库。这个地址必须是兼容本项目协议、且你有权使用的检索接口；普通网站页面、图片详情页、Tenor/GIPHY/KLIPY 原始 API 地址不能直接替代该接口。

检索服务接收 `GET <服务地址>?q=<简短检索词>&limit=1`，返回 JSON：`{"stickers":[{"url":"https://images.example.com/cheer.gif","alt":"开心庆祝","animated":true}]}`。没有结果返回 `{"stickers":[]}`。占位域名不是真实服务。配置 Key 后，检索请求使用 `Authorization: Bearer <key>`，仅携带检索词，不发送整段会话。

## 图片来源与密钥

默认只允许与检索服务同源的图片。使用独立 CDN 时，在“额外允许的图片来源”每行填写一个完整来源，例如 `https://images.example.com`，不带具体图片路径，最多 8 个。图片不附带检索 Key，只允许受支持的真实图片格式，不接受远程 SVG、HTML 或未允许的来源。

表情服务 Key 只保留在服务进程内，留空保留，清除需勾选后保存；重启后重新填写或设置 `STICKER_API_KEY`。网络检索失败不阻止文字回复。停用表情会阻止今后再次选择；删除上传图片后，旧聊天中的图片可能无法加载，但原来的文字说明保留。

## 表情联动场景与表达强度

在上传表情时填写“表情联动场景”和“表情表达强度”，或在已有表情的“编辑名称与标签”里调整“联动场景”“表达强度”并保存。可选场景为通用、安慰陪伴、庆祝、思考、休息、问候、感谢；强度 1 轻柔、2 明显、3 强烈。内置六张表情已标注，之前上传的素材默认为通用、强度 2，可随时修改。这些是用途标签，不代表应用已自动识别图片含义。

“设置 → 让回应贴合此刻 → 表情包随情绪回应”控制主动联动，保存后生效。疲惫或倾诉时自动筛选轻柔的本地安慰／休息素材，避免庆祝图和无法分类的联网图片；专注解决任务时不主动配图。每次最多一张，自动表情避免连续发送和近期重复。明确要求表情可绕过普通场景与频率筛选，仍受表情总开关、素材启用状态和原有图源配置控制。
