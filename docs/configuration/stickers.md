# 本地表情包与联网补充

适用于栖忆 1.0.0。进入“设置 → 让对话多一点表达”，调整后点击“保存媒体设置”。媒体设置与模型、邮件设置分别保存。

## 不配置联网服务也能使用

默认内置 6 张原创小叶贴纸。开启“允许 AI 搭配表情包”后，AI 根据聊天语境决定是否附图，每次最多一张，也可以不发送。为避免重复，最近两条 AI 回复使用过的表情会暂时排除。需要模型连接成功，普通文字模型即可按文字描述选图，不要求视觉模型。

在“本地表情图库”选择 PNG、JPEG、GIF 或 WebP，填写名称、使用场景和标签，点击“加入本地图库”。选图依据是这些文字，应用不会把图片内容自动传给聊天模型。每张最多 4 MiB、宽高不超过 4096；上传图库最多 100 张、合计 64 MiB。重复图片按内容去重。动图需要点击后加载和播放。

## 联网补充的服务地址

本地优先，没有合适素材且允许联网补充时才查询已配置服务。表情检索地址默认留空，留空就只用本地图库。这个地址必须是兼容本项目协议、且你有权使用的检索接口；普通网站页面、图片详情页、Tenor/GIPHY/KLIPY 原始 API 地址不能直接替代该接口。

填写部署后的完整 `https://<图库域名>/api/v1/stickers/search`，不带 `q`、`limit` 或 Key；占位域名不是真实服务。图库需返回含义、表达情绪、适用场景、禁用上下文、强度及图片属性等完整资料，只有旧式 URL 和名称的响应不能用于新候选。AI 参考这些语义资料选择图片，不需要视觉模型。

聊天服务只发送表达关键词及场景、情绪、强度上限和禁用上下文，不上传聊天原文或记忆。本地有匹配时不预取远程；否则策略允许时，在原有主模型请求前准备候选，每轮最多一次远程检索，不增加模型调用。最多 16 个候选、每次最多一张表情，也可以不发。无匹配、资料无效、鉴权失败、限流或超时都保留正文。

## 图片来源与密钥

在“表情服务 API Key”填写同时具备 `catalog:read`（检索）和 `images:read`（读图）权限的专用只读 Key。只具备检索权限时能取资料，但图片会显示“表情暂时无法加载”。检索及图片 GET／HEAD 均由聊天后端携带 Key；浏览器通过同源图片代理读取，不要把 Key 拼入网址。

新图库的检索和图片必须同源。旧的“额外允许的图片来源”每行一个来源、最多 8 个，仅用于已有历史图源，不会收到图库 Key。图片只允许受支持的真实格式，不接受远程 SVG、HTML 或跳转，不持久缓存原图；失败时显示替代提示，动图仍需点击加载。

Key 只保留在服务进程内，留空保留，清除需勾选后保存；重启后重新填写或设置 `STICKER_API_KEY`。轮换 Key 时保持完整检索地址不变，历史远程图片使用新 Key 读取。更换完整检索地址会影响历史图，切换前先核验旧引用并安排迁移。图库停用素材后不再搜索，但已发布原图按后端约定仍可用于历史；网络中断时远程历史图可能不可读。本地表情保持原有存储方式，删除上传图片后旧图无法恢复。

## 表情联动场景与表达强度

在上传表情时填写“表情联动场景”和“表情表达强度”，或在已有表情的“编辑名称与标签”里调整“联动场景”“表达强度”并保存。可选场景为通用、安慰陪伴、庆祝、思考、休息、问候、感谢；强度 1 轻柔、2 明显、3 强烈。内置六张表情已标注，之前上传的素材默认为通用、强度 2，可随时修改。这些是用途标签，不代表应用已自动识别图片含义。

“设置 → 让回应贴合此刻 → 表情包随情绪回应”控制主动联动，保存后生效。疲惫或倾诉时自动筛选轻柔的本地安慰／休息素材，避免庆祝图和无法分类的联网图片；专注解决任务时不主动配图。每次最多一张，自动表情避免连续发送和近期重复。明确要求表情可绕过普通冷却限制，远程候选仍须满足场景、情绪、强度上限及禁用上下文。通用场景不是通配符；严肃倾诉、哀伤及医疗／安全话题不检索远程图，明确要求也不能绕过。
