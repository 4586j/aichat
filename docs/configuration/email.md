# 邮件、SMTP 与授权码

适用于栖忆 1.0.0。支持纯文本邮件、抄送和密送。手动写信不依赖模型；AI 起草需要模型已配置。AI 和定时任务不会自动发信。

## 准备 SMTP 信息

从自己的邮箱服务商后台或文档获取 SMTP 主机、端口、加密方式、用户名和授权码。有些服务要求先开启 SMTP，再生成独立授权码；不能假定网页邮箱的登录密码一定适用。不同服务商的限制不同，本指南不提供通用真实账号或密码。

进入“设置 → 把想说的话，寄出去 → 邮件服务 · SMTP”。主机只填域名或 IP，例如 `smtp.example.com`，不要填 `smtp://`、`https://`、端口或路径。选择 TLS（常用端口 465）或 STARTTLS（常用端口 587），端口以服务商说明为准。应用强制加密并校验证书，不支持明文 SMTP。

## 用户名、密码和发件邮箱

用户名通常为完整邮箱地址。只有服务商明确允许免认证中继时才留空。授权码填写在“SMTP 密码 / 邮箱授权码”，不要贴进聊天。发件邮箱必须为该 SMTP 账号获准发送的地址；可选填写发件人名称。

点击“保存邮件设置”后再点击“测试已保存的 SMTP 连接”。测试只检查连接与认证，不发送邮件，也不能保证该发件地址有投递权限。更换主机或用户名时，旧密码会被清除，需要重新填写。留空保留已有运行期密码；勾选清除后保存才会移除。

普通配置持久化，密码只保留在服务进程内。重启后重新填写或使用 `SMTP_PASSWORD` 环境变量。使用环境变量时，先保存普通配置，再重启服务加载密码。保存成功后密码输入框清空是正常行为，不代表服务端没有密码。

## 写信与确认发送

点击顶部信封按钮。收件人填纯邮箱地址，多个用逗号分隔；收件、抄送、密送合计最多 20 个不同地址。主题最多 200 字符，正文最多 50000 字符。当前不支持附件或 HTML。

“让 AI 帮我起草”只把填写的起草需求交给模型，生成可编辑的主题和正文，不带入 SMTP 凭据和收件地址。聊天回复的“写成邮件”把该条回复复制为正文。草稿只在当前页面内存中保留，刷新后丢失。

点击“预览邮件”核对发件人、收件／抄送／密送地址、主题和正文，再点击“确认发送”。预览有效期 10 分钟；修改正文、配置或重启后需重新预览。同一预览重复确认不会重复发信，密送地址不出现在收件人看到的邮件头中。

## 如何判断发送结果

“查看发送记录”保留最近 100 次发送尝试，含正文、地址和接受／拒绝名单，可逐条删除。“服务器已接受”表示 SMTP 已接受提交，最终送达仍需关注退信；部分拒绝会列出具体名单。连接在 DATA 阶段中断或服务中断时，状态可能为“结果待核实”，先检查邮箱或收件情况再决定是否写新邮件，避免重复发送。系统不自动重试，删除本地记录不能撤回邮件。
