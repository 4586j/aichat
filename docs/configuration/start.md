# 首次启动与配置顺序

适用于栖忆 1.0.0。这里描述的是本项目已实现的行为；部署地址、模型名称和邮箱凭据由使用者自行提供。

## 安装与打开

安装 Node.js 22.18.0 或更高版本及 npm。在项目目录依次执行 `npm ci`、`npm start`，浏览器打开 `http://127.0.0.1:4317`。保持服务终端运行，按 Ctrl+C 停止。项目无需前端构建或单独安装数据库。服务只监听本机；手机布局适配不代表其他设备能通过网络访问这个本机服务。

## 推荐配置顺序

1. 进入“设置”，先配置模型的 Base URL、模型名称、API Key，点击“保存设置”，再点击“测试已保存的连接”。模型成功连接后才能聊天、使用 AI 起草和询问配置问题。
2. 表情包的 6 张内置贴纸可直接使用；需要更多素材时上传本地图片。联网表情服务可以先留空。
3. 使用自己的音乐平台时填写“音乐服务地址”；未填写时不会访问音乐服务，普通聊天和邮件仍可使用。
4. 需要发信时填写 SMTP 配置，手动测试后写信。手动写信不依赖 AI 模型。
5. 每类设置分别保存。更改模型设置后，不会同时保存尚未提交的媒体或邮件设置。

## 模型未配置时如何获得帮助

首次发言时，如果尚未填写模型，聊天会显示由应用生成的“本地配置助手”消息，包含快捷配置按钮和三步配置方法。第一句话保留在输入框，不调用模型、不创建空会话，重复点击发送不会叠加引导。点击“快捷配置模型”可直接填写 Base URL、模型 ID 和 API Key；保存不自动测试或发送，之后可手动测试，再点击“继续发送”。取消配置或切换页面不会清除当前聊天草稿；本地引导不保存为 AI 回复，也不进入聊天记忆。刷新页面后未发送的草稿不会保留。

打开“设置”中的“配置指南”，可以直接阅读内置的六份配置文档，不需要模型，也不需要网络。配置好模型以后，可在聊天中询问“栖忆的邮件授权码在哪里填”“音乐服务地址怎么设置”等问题；应用会检索相关指南片段交给模型，并在回复下方展示文档依据。模型可以解释步骤，不会替用户保存设置或测试连接。

## 数据与运行期密码

普通设置和数据保存在 `data/agent.sqlite`。备份前正常停止服务，复制整个 `data/` 目录。本地数据库没有加密。模型 API Key、音乐 API Key、表情服务 API Key、SMTP 密码只保留在服务进程内存中，不写入数据库。重启后需要重新填写，或在启动前设置环境变量。

## 环境变量与 .env

复制项目的 `.env.example` 为 `.env`，只在自己设备中填写所需值。普通的 `npm start` 和 `npm run dev` 不会自动读取 `.env`；显式加载使用 `node --env-file=.env server.mjs`。常用变量为 `PORT`、`AGENT_DATA_DIR`、`AI_API_KEY`、`MUSIC_API_KEY`、`STICKER_API_KEY`、`SMTP_PASSWORD`。主机、用户名等普通配置仍需在界面中保存。`.env` 已被 Git 忽略，真实密码、账号 Cookie 和 API Key 不应写入文档或提交到 GitHub。
