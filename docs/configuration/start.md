# 首次启动与配置顺序

适用于栖忆 1.0.0。这里描述的是本项目已实现的行为；部署地址、模型名称和邮箱凭据由使用者自行提供。

## 安装与打开

安装 Node.js 22.18.0 或更高版本及 npm。在项目目录依次执行 `npm ci`、`npm start`，浏览器打开 `http://127.0.0.1:4317`。保持服务终端运行，按 Ctrl+C 停止。项目无需前端构建或单独安装数据库。服务只监听本机；手机布局适配不代表其他设备能通过网络访问这个本机服务。

## 推荐配置顺序

1. 进入“设置”，先配置模型的 Base URL、模型名称、API Key，点击“保存设置”，再点击“测试已保存的连接”。模型成功连接后才能聊天、使用 AI 起草和询问配置问题。
2. 表情包的 6 张内置贴纸可直接使用；需要更多素材时上传本地图片。联网表情服务可以先留空。
3. 使用自己的音乐平台时填写“音乐服务地址”；未填写时不会访问音乐服务，普通聊天和邮件仍可使用。
4. 需要发信时填写 SMTP 配置，手动测试后写信。手动写信不依赖 AI 模型。
5. 每类设置分别保存。更改模型设置后，不会同时保存尚未提交的媒体或邮件设置。

## 模型未配置时如何获得帮助

首次发言时，如果尚未填写模型，聊天会显示由应用生成的“本地配置助手”消息，包含快捷配置按钮和三步配置方法。第一句话保留在输入框，不调用模型、不创建空会话，重复点击发送不会叠加引导。点击“快捷配置模型”可直接填写 Base URL、模型 ID 和 API Key；保存不自动测试或发送，之后可手动测试，再点击“继续发送”。取消配置或切换页面不会清除当前聊天草稿；本地引导不保存为 AI 回复，也不进入聊天记忆。刷新页面后未发送的草稿不会保留。

打开“设置”中的“配置指南”，可以直接阅读内置的六份配置文档，不需要模型，也不需要网络。配置好模型以后，可在聊天中询问“栖忆的邮件授权码在哪里填”“音乐服务地址怎么设置”等问题；应用会检索相关指南片段交给模型，并在回复下方展示文档依据。模型可以解释步骤，不会替用户保存设置或测试连接。

## 数据与运行期密码

普通设置和数据保存在 `data/agent.sqlite`。备份前正常停止服务，复制整个 `data/` 目录。本地数据库没有加密。模型 API Key、音乐 API Key、表情服务 API Key、SMTP 密码只保留在服务进程内存中，不写入数据库。重启后需要重新填写，或在启动前设置环境变量。

## 环境变量与 .env

复制项目的 `.env.example` 为 `.env`，只在自己设备中填写所需值。普通的 `npm start` 和 `npm run dev` 不会自动读取 `.env`；显式加载使用 `node --env-file=.env server.mjs`。常用变量为 `PORT`、`AGENT_DATA_DIR`、`AI_API_KEY`、`MUSIC_API_KEY`、`STICKER_API_KEY`、`SMTP_PASSWORD`。主机、用户名等普通配置仍需在界面中保存。`.env` 已被 Git 忽略，真实密码、账号 Cookie 和 API Key 不应写入文档或提交到 GitHub。

## 宠物小窝与陪伴偏好

点击顶部宠物头像／爪印按钮打开“宠物小窝”，也可从设置页的宠物区域打开。内置四款 AI 原创 Q 版形象：奶油猫“团团”、柴犬“豆包”、垂耳兔“糯米”和小狐狸“栗栗”。点击形象卡切换宠物，在“给它取个名字”中填写最多 20 个字符后保存。每种宠物有独立的名字、陪伴点数和摸摸、点心、玩耍记录，保存在本地 SQLite。

点击宠物形象可以摸摸，也可以在小窝中“喂点心”“玩一会儿”。摸摸与玩耍各加 1 点，点心加 2 点，同一宠物每秒最多记录一次互动；没有饥饿惩罚或每日打卡要求。聊天等待、回复完成和实际音乐播放时有轻动效，不会因此调用额外模型或增加互动点数。当前动效通过形象整体的呼吸、轻摆和跳跃实现。

关闭“开启轻动效”可静止陪伴，系统“减少动态效果”也会禁用动画。取消“在聊天中显示宠物”可以隐藏陪伴卡片和手机紧凑条，顶部爪印入口保留，随时可以重新显示。宠物图片随项目提供，不需要图片服务、联网、API Key 或模型配置；手机软键盘弹出时收起紧凑陪伴条以保留输入空间。宠物偏好与记录只用于本地展示，不自动写入聊天记忆或上传给模型。

## 对话状态与手动调整

聊天工具栏下方的状态栏把用户与 AI 角色分开：“你”显示当前情绪、精力和当前需要，“角色”显示表达状态与主动程度；右侧只显示熟悉阶段。点击状态栏进入“此刻的对话状态”，可展开“查看判断依据”查看本会话的用户原话、消息编号、判断把握和有效期。这是辅助推测，不能作为心理诊断；没有可靠依据时显示未知或默认状态。

要修改情绪、精力、需要、角色状态或主动程度，勾选对应的“由我指定”，选择值、按需填写备注，再点击“保存状态修改”。情绪可选择一至两项，强度为 1～5。手动指定在有效期内优先，取消勾选并保存后，下次发言恢复自动判断。短期状态只在当前会话内生效，最多 30 分钟后过期，不会带到其他会话；修改仅用于后续回复，不改写历史消息，也不会把状态字段写为长期记忆。备注只在本地展示，不随状态字段提供给模型。

“状态辅助方式”可选择“AI 辅助判断，手动指定优先”“只使用我指定的状态”或“关闭状态辅助并清空临时状态”。“清空本会话状态”仅清空短期状态，保留聊天、记忆和熟悉程度。AI 自动判断与聊天共用一次模型请求，不增加独立分析请求；只使用手动状态和关闭状态辅助时不要求模型生成状态分析。疲惫或想被倾听时，宠物会临时静止陪伴，不修改你保存的动效偏好。

## 熟悉程度与计算依据

熟悉程度按角色独立记录，以“初识”（0～24 分）、“逐渐熟悉”（25～59 分）、“熟悉”（60～100 分）显示。具体分数放在状态详情中的“熟悉程度”区域；展开“查看分数依据”可查看公式和计入的资料。该指标反映已确认资料量，不代表信任、好感或操作授权。

自动计算只计入该角色置信度至少 0.7、活跃、不重复的非摘要记忆：你手动添加的，或你打开记忆编辑器、核对并保存正文确认过的提取记忆。每条 8 分，每类资料 3 分，有重复提及的记忆每条另加 2 分（最多 10 条），总分上限 100。只固定或恢复一条自动提取记忆，不会把它视为已确认。删除、归档或编辑资料后会重新计算；暂时不聊天不扣分。模型不能直接提高熟悉分数。

需要自行调整时，勾选“手动设定熟悉程度”，填写 0～100 分和“手动设定的依据”，保存即可。取消该勾选并保存则恢复自动计算。手动熟悉程度按角色持久保存，不受短期状态的 30 分钟有效期影响；新会话会沿用该角色的熟悉阶段，但不会沿用其他会话的短期情绪和需要。

## 回应联动与独立开关

打开“设置 → 让回应贴合此刻”，分别调整“表情包随情绪回应”“低频自然推荐歌曲”“宠物随对话状态表现”，点击“保存回应联动设置”。每项独立控制。关闭表情或歌曲联动后仍可明确索要相应内容，原有媒体总开关继续生效；宠物联动关闭后保留普通等待、回复和听歌表现。保存只修改本地偏好，不请求模型、不测试服务或自动播放。

当前需要优先：任务／建议场景以清楚步骤为主，倾诉时温和陪伴，疲惫时安静休息，开心闲聊时适当庆祝。联动与聊天复用一次模型请求，本轮原话校验后即可生效，手动状态优先。助手消息下可展开“本轮回应依据”查看当时采用的状态与原话。正常回复默认突出表情或歌曲其中一种，明确同时要求时可同时给出。

宠物随当前有效状态呈现安静、温和陪伴、专注、短暂庆祝和听歌轻摆，继续使用四款原有形象的整体轻动效。关闭轻动效或系统开启“减少动态效果”时静止显示，情绪联动不会修改已保存的宠物名字、动效偏好、互动记录或陪伴点数。
