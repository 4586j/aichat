# 音乐平台与背景播放

适用于栖忆 1.0.0。音源使用你自己的音乐平台，当前适配其 Flask HTTP 接口、本地曲库、QQ 和网易云搜索；本项目不会导入音乐平台的账号 Cookie。

## 服务地址在哪里填

进入“设置 → 让对话多一点表达 → 你的音乐平台”。开启“允许歌曲推荐与背景播放”，在“音乐服务地址”填写实际运行的服务基础地址，不要加 `/api/search` 等具体接口。开启鉴权时填写该音乐平台分配的 API Key，选择在线补充来源，再点击“保存媒体设置”。

音乐服务地址默认留空，必须由使用者根据实际部署填写。留空时不尝试本机端口、旧源码中的公网地址或其他备用服务。不能根据示例地址断言服务可用。源项目主程序默认端口曾为 10001，但实际部署可能不同，须自行确认；`http://127.0.0.1:10001` 只是同机运行时的地址格式示例。

## 保存与测试

音乐平台需要先启动，且能被运行栖忆 Node.js 的机器访问。保存后点击“测试已保存的音乐连接”，应用会读取服务 `/api/status`。保存本身不测试，也不自动读取曲库。Key 只保留在服务进程内存中，重启后重新填写或设置 `MUSIC_API_KEY`；服务端通过 `X-API-Key` 转发，浏览器播放 URL 不携带 Key。

## 音乐平台需要提供的接口

- `/api/status`：服务与来源状态。
- `/api/library`：本地歌曲列表与元数据。
- `/api/search?keyword=...&source=qq或netease`：补充在线搜索。
- `/api/local_play?name=...`：播放本地文件。
- `/api/stream?songmid=...&source=...&quality=320`：在线播放，需支持音频和 Range。
- `/api/local_cover?name=...`：可选的本地封面。

鉴权、第三方登录状态、可播放权限及音频解析由原音乐平台处理。状态接口成功不保证每首在线歌曲都能播放。

## 如何播放与设为背景音乐

点击顶部音符按钮，可搜索歌曲、浏览本地曲库并建立播放队列。优先本地，匹配不足时用选定来源补充。聊天歌曲卡片可点击“播放这首歌”或“设为背景音乐”。音频需要用户点击后启动，AI 推荐不会自动出声。

播放器支持音量、进度、上一首／下一首及循环；切换六个页面继续播放，刷新不会自动播放。播放推荐歌曲时暂时中断原背景音乐，结束后恢复；手动暂停、关闭或切歌会取消恢复。手机锁屏后持续播放受浏览器和系统限制。修改音乐服务地址后，旧卡片需重新搜索，避免把旧歌曲标识发到另一台服务。

## 情绪联动、推荐间隔与反馈

在“设置 → 让回应贴合此刻”开启“低频自然推荐歌曲”，并点击“保存回应联动设置”。主动推荐每 5 次成功回复最多一次，前四次不主动推歌；疲惫或主动程度为“少追问”时，间隔为 10 次。想被倾听、需要建议或解决问题时减少打扰，不主动推荐。状态未知、音乐服务地址未填、联动关闭或本会话暂停推荐时，不主动生成歌曲卡片。明确要求推荐／点歌可绕过普通间隔和会话静音，仍受“允许歌曲推荐与背景播放”总开关控制。

歌曲只作为可点击的卡片展示，不因情绪变化自动播放、切歌、调音量或改队列。仍使用你的音乐平台，优先本地曲库，不足时搜索选定在线来源。当前适配器没有可靠的歌曲情绪、节奏或歌词分析数据，推荐只可结合已确认偏好和已有歌曲信息，不应把模型生成的推荐理由当作音频分析结果。

卡片下的“这次不需要”仅收起这一条歌曲，可“重新显示这首歌”；“本会话不再主动推荐”会同时收起这一条，并在当前会话内停止主动推歌。静音保存在本地，刷新／重启后仍有效，新会话独立；仍可明确点歌。点击聊天状态栏下方“恢复本会话推荐”重新开启。反馈不暂停当前音乐，也不改变用户情绪、长期记忆或熟悉程度。
