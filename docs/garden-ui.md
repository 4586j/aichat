# 园林前端与接口联调

正式入口是 `/`。`public/garden-preview.html` 保留为本地视觉参考，示例聊天不参与正式应用。

## 界面文件

- `public/index.html`：导航、主题控制、园林 SVG 符号和持久播放器备用容器。
- `public/garden.css`：园林配色、窗框按钮、布局、窄屏适配和夜间主题；在原有功能样式之后加载。
- `public/garden-ui.js`：共享插画、主题与场景动画偏好、真实播放器的位置管理。
- `public/app.js`：沿用本地 API 请求、表单、错误处理和草稿状态，渲染正式聊天、历史会话与记忆统计。
- `public/pets.js`：沿用宠物服务和动作渲染，增加侧栏快速切换、摸摸与喂食入口。

聊天页保持窗口高度，只有聊天记录滚动，输入框固定在消息区下方。角色、记忆和播放器位于右栏，宠物位于左侧导航下方。窄屏使用顶部导航、紧凑宠物和底部信息区；软键盘出现时优先保留输入区域。管理页面和弹窗可以在自身区域阅读长表单，页面外层不滚动。

## 真实数据连接

| 操作 | 数据来源与行为 |
| --- | --- |
| 初始化与刷新 | `GET /api/bootstrap`，读取角色、会话、文档、记忆、任务及各功能设置 |
| 创建和读取聊天 | `POST /api/conversations`、`GET /api/conversations/:id` |
| 发送消息 | `POST /api/conversations/:id/messages`，保留返回的引用、记忆依据和回复联动信息 |
| 历史对话 | 按当前角色筛选并分页显示；打开会话只读取消息，不重新请求模型 |
| 保存回复为记忆 | 先打开现有记忆编辑器，允许修改内容；点击“添加记忆”才调用记忆接口 |
| 侧栏统计 | 从当前角色的活跃、固定记忆和共享文档计算，不使用预览数字 |
| 宠物切换与互动 | `PUT /api/pets/settings`、`POST /api/pets/interact`；保留服务端修订号和互动记录 |
| 背景音乐 | 沿用 `/api/music/*` 和真实 `audio` 元素；移动播放器控制节点，不重新创建音频节点 |
| 邮件、知识库、任务和设置 | 沿用已有功能模块和接口；保留显式保存、预览及确认流程 |

主题和场景动画只在浏览器保存外观偏好。改变外观不会修改模型设置、调用模型或发送邮件。

## 验证

```sh
npm test
npm run test:ui
```

浏览器测试通过 `tests/ui-fixture.mjs` 使用内存数据库、离线模型及媒体和邮件替身，不读写真实用户数据。`tests/garden-browser.spec.mjs` 覆盖窗口布局、保存回复为记忆、历史分页、真实消息读取、外观持久化和草稿保留；其他浏览器测试覆盖完整业务链路。

实际模型、音乐平台和 SMTP 连接使用用户在“设置”中保存的地址与凭据，并通过对应的显式连接测试验证。项目启动后访问 `http://127.0.0.1:4317`。
