# 栖忆 · MEMORY STUDIO

栖忆是一个面向本地、单用户使用的 AI 对话与记忆空间。它把角色聊天、个人知识库、长期记忆和定时任务放在同一个中文界面中，使用 Node.js 提供本地服务，使用 SQLite 保存数据。

## 项目功能

- **角色对话**：创建和切换不同角色，保留多段会话；回答可结合相关知识片段与角色记忆，并展示引用来源和召回的记忆。
- **人设工坊**：编辑角色名称、简介、语气、开场白与系统提示词；从聊天记录中分析指定人物的表达风格，生成可编辑的人设草稿，确认后再创建角色。
- **本地知识库**：导入 TXT、Markdown、JSON、文字型 PDF 和 DOCX，在本地提取文字、分块并进行关键词检索。知识库由全部角色共享；单个文件最大 8 MiB，提取后的文字最多 30 万字符。文本文件需使用 UTF-8 编码，扫描型 PDF 需先自行进行 OCR。
- **长期记忆**：按角色保存事实、偏好、目标、约束与摘要；支持手动记录、从对话总结、按消息数或时间自动总结，以及编辑、固定、归档、恢复和删除。记忆会根据重要性、置信度、访问情况与时间衰减评分，维护时将符合条件的弱记忆归档。
- **记忆图谱**：手动填写或通过模型提取实体与关系，用交互图谱查看记忆、关系和原文证据，支持搜索、筛选与关联召回。
- **定时任务**：支持应用内提醒、角色上下文总结和 AI 提问，可设置一次性执行或按分钟固定间隔重复，并查看执行状态与结果。
- **模型设置**：连接支持 OpenAI 兼容聊天接口的远程或本机模型服务，配置 Base URL、模型名称与 API Key，并手动测试连接。

## 本地启动

### 环境要求

- Node.js **22.18.0 或更高版本**（见 `package.json` 中的 `engines`），并安装 npm。
- 支持 JavaScript 的现代浏览器。
- 使用 AI 功能时，需要可访问的 OpenAI 兼容模型服务；服务商要求认证时，还需准备 API Key。

项目使用 Node.js 内置的 SQLite，无需单独安装数据库，也无需构建前端。未配置模型时仍可启动界面、管理角色、导入和检索文档、手动管理记忆，以及使用应用内提醒。

### 安装并运行

```sh
git clone git@github.com:4586j/aichat.git
cd aichat
npm ci
npm start
```

如果已经在项目目录中，直接执行 `npm ci` 和 `npm start` 即可。

看到终端输出“栖忆 AI Agent 已启动”后，在浏览器打开：

[http://127.0.0.1:4317](http://127.0.0.1:4317)

开发时可使用自动重启模式：

```sh
npm run dev
```

运行期间保持终端中的服务进程开启，按 `Ctrl+C` 停止服务。

### 首次配置模型

1. 打开左侧“设置”，填写服务商提供的 **Base URL** 和 **模型名称**。
2. Base URL 填写接口基础地址，例如项目默认的 `https://api.openai.com/v1`。程序会自动追加 `/chat/completions`，不要把完整聊天接口地址填入此处。
3. 按服务要求填写 API Key；无需认证的本机兼容服务可留空。
4. 点击“保存设置”，再点击“测试已保存的连接”。测试会向模型发送一条实际请求。
5. 连接成功后，在“对话”中选择角色并开始聊天，也可先到“知识库”导入参考资料。

Base URL、模型名称和记忆设置会保存到本地数据库。界面输入的 API Key 仅保留在当前服务进程内，不写入数据库；重启服务后需重新输入，或通过 `AI_API_KEY` 环境变量提供。人物分析、记忆总结和图谱提取需要模型能够按提示返回有效的 JSON 内容。

### 可选环境变量

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| `PORT` | `4317` | 本地服务端口，范围为 `1`～`65535`。 |
| `AGENT_DATA_DIR` | 项目目录下的 `data/` | 数据目录，程序会在其中创建 `agent.sqlite`；自定义相对路径按启动命令所在目录解析。 |
| `AI_API_KEY` | 空 | 服务启动时读取的模型 API Key；Base URL 和模型名称仍需在界面中配置。 |

例如，在 Windows PowerShell 中更改端口后启动：

```powershell
$env:PORT = "4417"
npm start
```

此时访问 [http://127.0.0.1:4417](http://127.0.0.1:4417)。

`npm start` 和 `npm run dev` **不会自动读取 `.env`**。如需使用配置文件，可自行在项目根目录创建 `.env`，按需填写：

```dotenv
PORT=4317
AGENT_DATA_DIR=./data
AI_API_KEY=替换为你的密钥
```

然后显式加载该文件启动：

```sh
node --env-file=.env server.mjs
```

该方式使用 [Node.js 的 `--env-file` 选项](https://nodejs.org/docs/latest-v22.x/api/cli.html#--env-filefile)。`.env` 已被 Git 忽略；无需认证的模型可省略 `AI_API_KEY`。

## 本地数据与使用范围

- 默认数据库为 `data/agent.sqlite`，保存角色、会话、提取后的文档文字、记忆、图谱、设置和任务记录。导入文档的原文件不保留，需自行保存原件。
- 备份前先正常停止服务，再复制整个数据目录；`data/` 已被 Git 忽略。本地数据库未加密。
- 服务仅监听 `127.0.0.1`，面向单用户本机使用。聊天、人物分析、记忆总结、图谱提取及 AI 任务会将相关文本发送至配置的模型；聊天请求还可能包含相关知识片段和长期记忆。
- 定时任务仅在服务运行时执行。关闭服务或电脑休眠时暂停；应用内提醒的结果在应用中查看。

## 测试

运行服务、存储、知识库、记忆、图谱、模型配置与调度相关测试：

```sh
npm test
```

运行浏览器界面测试：

```sh
npm run test:ui
```

界面测试默认使用本机已安装的 Google Chrome，也可通过 `PLAYWRIGHT_CHANNEL` 环境变量选择其他已安装的兼容浏览器通道，例如 `msedge`（参见 [Playwright 浏览器通道文档](https://playwright.dev/docs/browsers#google-chrome--microsoft-edge)）。测试会自动启动 `http://127.0.0.1:4318` 的独立服务，使用内存数据库与模拟模型回复，无需真实 API Key。运行前请确保该端口未被其他服务占用。HTTP 相关测试需要允许本机回环网络连接。

## 项目结构

```text
.
├── server.mjs              # 本地 HTTP 服务、静态资源与 API 路由
├── lib/
│   ├── service.mjs         # 角色、会话、设置等业务逻辑
│   ├── store.mjs           # SQLite 数据结构与存储
│   ├── model.mjs           # 模型请求与错误处理
│   ├── knowledge.mjs       # 文档分块与关键词检索
│   ├── document-worker.mjs # PDF / DOCX 文字提取
│   ├── memory.mjs          # 长期记忆总结、召回与维护
│   ├── graph.mjs           # 图谱提取、关系与证据管理
│   └── scheduler.mjs       # 定时任务调度
├── public/                 # 原生 HTML、CSS、JavaScript 界面与图谱
├── tests/                  # Node.js 测试、Playwright 测试与模拟服务
├── playwright.config.mjs   # 浏览器测试配置
└── package.json            # 依赖、运行脚本与 Node.js 版本要求
```
